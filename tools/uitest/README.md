# UI-проверки каталога (dev only)

Функциональный прогон нового каталога без браузера: jsdom исполняет реальные
`static/*.js` и ходит в `tools/mock_api.py` по HTTP. Проверяет каталог, карточку,
фильтры, пагинацию, доказательство, вкладки, ошибки и состояние URL.

```bash
cd tools/uitest
npm install
../../.venv/bin/python ../mock_api.py --port 8799   # в отдельном терминале
node harness.mjs
```

Если мок слушает другой адрес: `MOCK_URL=http://127.0.0.1:9000 node harness.mjs`.
Ожидаемый результат — «41/41 проверок пройдено» и код возврата 0.

## Проверка паспорта статьи

`node passport.mjs` проходит экран `#/passport` в реальном браузере: демо-значения,
фильтры, выбор строки, импорт общего формата, RAG `facts`, семи таблиц Solar,
ошибки импорта, CSV, привязка PDF, повторный импорт и навигация. Требует Chromium
Playwright и запущенный мок; ожидаемый результат — все проверки `ok`.

Проверки используют `static/` напрямую из репозитория, поэтому копия не нужна.
`node_modules/` не коммитится. Это инструмент разработки, а не продуктовый путь.

## Проверка входа и профиля

`node auth.mjs` (или `npm run auth`) проходит экран первого входа и профиль в
реальном браузере: без серверной сессии каталог закрыт, регистрация и вход
открывают мастер, поповер работает с клавиатуры, профиль сохраняется после
перезагрузки, выход завершает серверную сессию, но не стирает запись, повторный
вход возвращает профиль, неверный пароль и незарегистрированный email
отклоняются, а при запрете `localStorage` сессия работает, а профиль живёт в
памяти вкладки. Ожидаемый результат - «41/41 проверок пройдено».

Аккаунт для старых проверок лежит в `account.mjs`: вход обязателен, поэтому
`harness.mjs`, `wizard.mjs`, `e2e.mjs`, `passport.mjs` и `manual-profile.mjs`
кладут профиль в `localStorage` и cookie сессии мока до загрузки страницы.
JSDOM-проверки подменяют только `/api/auth/me`, остальное отдаёт настоящий мок.

## Проверка ручного профиля

`node manual-profile.mjs` (или `npm run profile`) проходит `/manual-profile` в
реальном браузере: загрузка PDF, готовый набор Solar, поиск подсказок, выбор
фрагмента, скачивание JSON и передача PDF из мастера на каталоге через IndexedDB.
Требует Chromium Playwright и запущенный мок; ожидаемый результат - «18/18 проверок
пройдено».

## Проверка в реальном браузере (опционально)

```bash
npm install
npx playwright-core install chromium
npm run e2e
```

Скрипт `e2e.mjs` проверяет сортировку, XSS-строку в поиске, пагинацию 28k,
фильтр метрики, диалог и Esc, загрузку PDF. Если Chromium лежит не в кэше
Playwright, укажите `CHROME_PATH=/path/to/chrome`.
