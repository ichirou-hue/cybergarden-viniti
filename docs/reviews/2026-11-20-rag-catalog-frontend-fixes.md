# Статус находок ревью RAG-каталога

Дата: 2026-11-20. Отчёт-источник: `docs/reviews/2026-11-20-rag-catalog-frontend.md`.
Ниже — что изменено после ревью и что осталось осознанным ограничением.

## Блокеры

- **B1 (точка входа `server.py`).** Backend не менялся: `server.py` — зона Мити, по условию задачи эндпоинты заменены заглушкой. Что сделано со стороны frontend:
  - README явно разделяет запуск `server.py` (прежняя версия) и новый каталог через `tools/mock_api.py`;
  - ADR-0008 фиксирует требование к backend: раздавать `static/**` и реализовать `/api/documents…`;
  - в `index.html` добавлены `<noscript>` и сообщение, если модули не загрузились за 4 с: вместо белого экрана пользователь видит команду запуска мока.
  
  Остаётся сделать Мите: расширить раздачу статики и реализовать контракт из ADR.

## Исправлено

- **F1–F3 (таймеры, гонки, устаревшая отрисовка):** у каждого экрана снятие debounce по `AbortSignal`, номер запроса (`request++`) с отбрасыванием устаревших ответов, проверки `signal.aborted` после `await` в роутере.
- **F4–F5 (область):** `X-Track` в загрузке и демо, `track` берётся из ответа, область документа выводится из префикса `document_id`; неизвестная область — явная ошибка без фолбэка; URL нормализуется.
- **F6 (глубокие ссылки):** `anchors/{id}.json` внесён в контракт ADR; ошибка якоря не заменяет карточку, а пишется в статус; мок отдаёт 404 на неизвестный якорь.
- **F7 (контракт мока):** реализованы `limit/offset` каталога, `counts.by_status`, `record_ids` и `source` у замечаний; `POST` проверяет `Content-Type` и размер; некорректные числа → 400.
- **F8 (переход к записи):** клик по `record_id` сбрасывает фильтры, ставит `?result=R…`, подсвечивает строку, раскрывает детали и ставит фокус.
- **F9 (маршруты вкладок):** ADR приведён к фактическому `tab=`; поддержан старый `view=` как совместимость.
- **F10 (доступность вкладок):** `role=tab`/`tabpanel`, `aria-controls`, roving `tabindex`, стрелки/Home/End, возврат фокуса на активную вкладку, `:focus-visible`, skip-link, `.sr-only`.
- **F11 (шапка):** DOI, `in_scope` с причиной, баннер `running`, экспорт скрыт для `running/queued/failed`.
- **F12:** отказ фасетов показывает предупреждение, поиск и «только с замечаниями» остаются.
- **F13:** ошибки вкладок локализованы внутри панели; пейджер/пустое состояние очищаются; `page` зажимается в диапазон.
- **F14:** `sq` читается из URL, цитата берётся как `fragment ?? quote`, `/sources` описан в ADR.
- **F15:** подписи полей сущностей из дескриптора, массивы через запятую, ссылки «показать результаты» для конфигурации/набора.
- **F16:** мок не роняет соединение на мусорных параметрах.
- **Мелочи:** не-JSON ответ даёт понятную ошибку; `decodeURIComponent` защищён; экран ошибки ведёт в каталог; дефолтная сортировка не пишется в URL; пустое состояние с кнопками загрузки/демо; `seconds(0)` → «—»; `value/checked` в `dom.js` ставятся свойствами; `kinds`/`entities[].columns`/`entityFilters` в дескрипторе; `<th scope>` в сводке; убраны вложенные шаблоны; дескриптор и ADR синхронизированы; мок отдаёт `Cache-Control: no-store`, поднят backlog, CSV — 30 колонок целевой схемы, JSON содержит результаты; загрузка в моке создаёт `partial` с честным предупреждением.

- `server.py` не тронут (зона Мити) — см. B1.
- Харнесс и e2e перенесены в `tools/uitest` и проверяют `static/` напрямую (43 + 15 проверок).
