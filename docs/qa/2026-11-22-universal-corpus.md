## Проверено

- Все файлы являются читаемыми PDF; контрольные суммы уникальны и закреплены в tools/fixtures/universal-papers.json.
- Текст извлекается на всех 196 страницах; это не замер точности текста.
- profile.json и schema.json соответствуют текущему universal профилю.
- Общие три CSV и 30 черновиков для документов имеют правильные заголовки/порядок полей.
- Просмотрены изображения первых страниц всех десяти PDF; названия соответствуют подборке.

Команда:

```sh
.venv/bin/python -X utf8 tools/universal_corpus.py --verify-only
```

## Ограничения

PDF-парсер выдал предупреждения об отсутствии необязательного fontTools для некоторых шрифтов. Они сохранены в parser_warnings технического отчёта. Читаемость PDF не означает правильность распознавания всех символов.

Настоящая LLM и полный разбор Docling не запускались. CSV пока пустые, служат шаблонами, а не эталонной разметкой или извлечёнными результатами. Шаблоны универсальные; официальный tools/gate.py для solar/RAG к ним не применяется.

Корпус исключён из Git правилом docs/materials/. Для повторного скачивания есть tools/universal_corpus.py и манифест с URL/хешами; существующие пользовательские PDF/CSV не перезаписываются.
