## Дефекты

### 🟡 D1. Вкладка «Фрагменты PDF» молча обрезает выдачу: 200 из 411

- **Где:** `static/document.js`, `renderSources()` — запрос `{limit: 200}` (строка ~714), пагинатора нет; счётчик показывает `data.total`.
- **Шаги:**
  1. Открыть `http://127.0.0.1:8799/#/doc/rag%3Ad020?tab=sources&track=rag`.
  2. Посмотреть счётчик и число строк таблицы.
  3. Для API: `curl 'http://127.0.0.1:8799/api/documents/rag%3Ad020/sources?limit=200'`.
- **Ожидалось:** доступны все 411 фрагментов (пагинация/«показать ещё») **или** явно написано «показано 200 из 411».
- **Фактически:** счётчик «Фрагментов: 411», в таблице 200 строк, пагинатора/кнопки «Ещё»/пометки об обрезке нет. API отдаёт `total=411, items=200`.
- **Почему важно:** в ADR у реальных статей 468–1194 фрагмента; пользователь видит счётчик 411 и считает, что просмотрел всё. Тот же жёсткий `limit: 200` есть у вкладки «Замечания» (`static/document.js:645`); на D020 всего 3 замечания, но на большом документе они также могут исчезнуть без следа.
- **Проверка:** `node browser_defects.mjs` — первая проверка падает; `node browser_document.mjs` фиксирует 200 строк.

### ⚪ D2. Глобальная строка статуса не очищается после успешного перехода

- **Где:** `static/app.js`, успешные ветки `route()` не вызывают `say("")`; ошибка пишется в `#status` в `catch` открытия source.
- **Шаги:**
  1. Открыть `http://127.0.0.1:8799/#/doc/rag%3Ad020/source/999999?track=rag`.
  2. Дождаться «Не удалось открыть источник: Источник не найден.».
  3. Нажать «Каталог» (или открыть D013).
- **Ожидалось:** после успешной загрузки каталога/другой карточки старая ошибка в `#status` исчезает.
- **Фактически:** каталог/карточка отрисованы, но внизу остаётся старая ошибка «Не удалось открыть источник…».
- **Почему важно:** пользователь видит ошибку на экране, где её нет; особенно заметно на демо после проверки битой ссылки.
- **Проверка:** `node browser_defects.mjs` — вторая проверка падает.

### ⚪ D3. Переход с валидной глубокой ссылки на несуществующий `source_id` оставляет старую модалку

- **Где:** `static/app.js` вызывает `dismissEvidence()` только когда в маршруте нет `/source/`; `static/evidence.js` в `openEvidence()` не закрывает диалог при ошибке якоря.
- **Шаги:**
  1. Открыть `#/doc/rag%3Ad020/source/1001?track=rag` — модалка с цитатой R001.
  2. В адресной строке заменить `1001` на `999999`, не закрывая модалку.
- **Ожидалось:** старая модалка закрывается (или в ней показывается ошибка); пользователь не видит чужую цитату.
- **Фактически:** модалка остаётся открытой с прежней цитатой `BM25 | Table 3 | Recall | 0.81` и заголовком «Источник · страница 5», хотя URL уже `/source/999999`, а в статусе «Источник не найден».
- **Почему важно:** редкий, но воспроизводимый stale-state; при правке URL/переходе по битой ссылке можно принять старую цитату за новую.
- **Проверка:** `node browser_defects.mjs` — третья проверка падает.

## Что проверено и претензий нет

- **Серверная пагинация:** D014 28 649 — в DOM только 50 строк, «Далее/Назад», зажим 573/-5/abc, последняя страница 49 строк.
- **URL как состояние:** вкладки, фильтры, `issues=1`, `sq`, `result=R001`; F5 восстанавливает состояние; `view=` совместимость; track из `document_id` приоритетнее `?track=`.
- **XSS/экранирование:** каталог и результаты с `"><img onerror=...>` — без alert, без img, title не меняется; все серверные тексты идут через `textContent`.
- **Ошибки API:** несуществующий документ (404, карточка с причиной), неизвестный маршрут, `limit=abc`/`offset=-5` (400 JSON), пустой поиск.
- **CSV:** 30 колонок совпадают с gold по порядку; D020 408 строк; все строки 30 полей; кавычки/разделители парсятся `csv.reader`; BOM; карточка и каталог отдают одинаковые байты. JSON валиден, 408 results.
- **Загрузка:** валидный PDF → карточка, `X-Track: rag`, `X-Filename`, `partial`, warning мока, документ появляется в каталоге; пустой файл/пустое тело отклоняются (413), text/plain — 415; Solar-раздел отключён и не смешивается, direct `X-Track: solar` создаёт solar-документ, deep link не рендерит RAG.
- **Мобильная ширина:** полноэкранный диалог, скролл таблиц, отсутствие горизонтального overflow, длинное имя файла (190 px + ellipsis), клавиатурные стрелки вкладок.
- **Доступность (частично):** `scope=col`, `aria-live`, `role=tab/tabpanel`, `aria-selected`, фокус в диалоге, Esc; клавиатурная навигация вкладок проверена.

- **Running status** — фикстуры нет; проверены `done/partial/failed/queued`.
- **Реальный CSV/JSON D014** — выгружал D020 (408 строк); 28k выгрузку не скачивал.
