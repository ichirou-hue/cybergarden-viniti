# Статус находок дизайн-ревью RAG-каталога

Дата: 2026-11-20. Отчёт-источник: `docs/design-reviews/2026-11-20-rag-catalog.md`.

## Блокеры

- **B1. Sticky-заголовок.** Таблицы теперь живут в ограниченном по высоте скроллере (`.results { max-height: min(72vh, 720px) }`), заголовок `<th>` фиксируется внутри него; проверено в Chromium: после `scrollTop = 400` верх `<th>` совпадает с верхом контейнера. У заголовка появилась тень.
- **B2. Таблицы на 1024/390.** Каждой таблице задан `min-width` (результаты 1024px, замечания 760px, фрагменты/сущности 640px, каталог 900px), включён горизонтальный скролл вместо разрыва слов; `overflow-wrap: anywhere` заменён на `break-word`; кнопки источника и ячейки «Группа» не переносятся; `colgroup` + `table-layout: fixed` для результатов.
- **B3. Читаемость доказательства.** Диалог расширен до 960px, PNG показывается в натуральную ширину без `max-height` (страница скроллится внутри диалога), добавлена ссылка «Открыть PDF» на нужную страницу; на мобильном — полноэкранный режим с заголовком в отдельной строке.

## Важное

- **F1. Вариант A.** Каталог и карточка собраны в белые панели; добавлены крошки «Каталог / RAG / D020», счётчики в мете (результаты, замечания, время), счётчики вкладок, ghost-кнопки PDF/JSON/CSV, осмысленные подписи «Все метрики / Любой k / Все наборы / Все конфигурации / Все статусы».
- **F2. Пустые состояния.** В каталоге пустое состояние вынесено из таблицы (не клиппится на мобильном), скрывает таблицу; в карточке счётчик пишет «Найдено 0», сообщение имеет `role="status"`, на мобильном блок сообщения поднят выше фильтров (CSS `order`).
- **F3. Загрузка.** Показывается имя выбранного файла (с обрезкой), «Сначала выберите PDF» при пустом выборе, сообщение о процессе рядом с формой (`#uploadState`), label визуально блокируется на время загрузки.
- **F4. Ошибки и статусы.** Сетевые ошибки локализованы, в каталоге и результатах есть «Повторить» и `role="alert"`; для Solar — человеческий заголовок «Раздел пока не подключён» с `h1` и ссылкой на RAG; queued/running получили отдельный экран «Документ ещё не обработан»; для скана убран дублирующий баннер «частично», исправлено «со страниц»; у failed скрыта бесполезная панель фильтров.
- **F5. Доступность.** `:focus-visible` на тёмной шапке светлый; при первой загрузке фокус не перехватывается (skip-link работает), после смены маршрута — на `main`; активация вкладки мышью/Enter возвращает фокус на активную вкладку; раскрыватель и кнопки источника увеличены; таблицам добавлены `caption`, диалогу — `h2`; `aria-controls` у раскрывателя.
- **F6. Пагинация.** После «Далее/Назад» сбрасывается внутренний скролл, таблица подводится к началу, фокус переходит на счётчик; ширины колонок стабильны между страницами.

## Улучшения

- Сводка разложена в две колонки, таблицы не зажаты в 320px.
- Числа сгруппированы (`28 649`), длительность печатается минутами (`3 мин 4 с`), десятичные — с запятой.
- `document.title` меняется на каталоге и карточке.
- Добавлены hover-состояния кнопок и ссылок.
- «В области» отделено серым бейджем от статуса.
- У сущностей появилась отдельная колонка «Действие».
- Кнопки источника стоят в одной строке, строки таблицы стали вдвое ниже.

## Осознанно оставлено

- Полноценные карточки вместо таблиц на 390 не делались: выбран горизонтальный скролл с `min-width` — он предсказуем и не ломает данные.
- Кроп вокруг `bbox` не добавлялся: контракт отдаёт страницу PNG; читаемость обеспечена масштабом и ссылкой на PDF.
- Токены CSS не выделялись в отдельную систему — хардкоды палитры остались локальными (не блокирует Solar).
