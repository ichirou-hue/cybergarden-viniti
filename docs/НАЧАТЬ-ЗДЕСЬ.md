# Начать здесь

Материалы для команды хакатона ЮФУ/ВИНИТИ. Исходный код приложения находится в отдельном репозитории: [cybergarden-viniti](https://github.com/ichirou-hue/cybergarden-viniti). Если репозиторий приватный, каждому участнику нужен выданный владельцем доступ; наличие этой папки на Google Drive доступ к исходникам не предоставляет.

## Порядок знакомства

1. Прочитайте [краткий обзор кейса](materials/case-overview.pdf).
2. Посмотрите [гайд запуска приложения](2026-11-20-project-launch.md), затем сам [README репозитория](../README.md), чтобы поднять прототип.
3. Изучите [старт команды и распределение](2026-11-20-team-start.md).
4. Перейдите к [разбору кейса и данных](requirements/2026-11-20-hackathon-case-analysis.md) и [рабочему плану](requirements/2026-11-20-team-plan.md).
5. Откройте комплект по своей области (см. ниже); архивы распаковывайте раздельно.
6. Для профильного извлечения данных из PDF изучите [гайд profile extraction core](2026-11-20-profile-core-guide.md).
7. Ознакомьтесь с [утверждённым процессом обработки](requirements/2026-11-21-approved-processing-pipeline.md) и [дорожной картой UX профилей](requirements/2026-11-21-profile-ux-roadmap.md): в них отдельно отмечены реализованное и будущие требования.

## Материалы

Код и Markdown-документация хранятся в GitHub. Тяжёлые исходные материалы передаются через Google Drive; каталог `docs/materials/` исключён из Git.

**Ссылка на Google Drive:** пока не добавлена — требуется адрес общей папки.

После клонирования репозитория скачайте с Drive три файла ниже в `docs/materials/`, сохранив указанные имена. Тогда относительные ссылки на материалы заработают. При передаче всей папки `docs` через Drive файлы уже находятся на месте.

- [Обзор кейса (PDF)](materials/case-overview.pdf)
- [Комплект участников Solar (ZIP)](materials/solar-participant-kit.zip)
- [Комплект участников RAG (ZIP)](materials/rag-participant-kit.zip)

Распакуйте Solar и RAG в разные каталоги: внутри встречаются одинаковые имена документов D/P, относящиеся к разным областям. Не объединяйте содержимое архивов в одну папку.
